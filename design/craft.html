Verdict CommentModifiedRound 2 · draft

Comment anchoring

Anchors bind a comment to a position in a file revision so feedback follows the code across rounds. An anchor stores the file id, a line, and the function arity it was attached to.

Resolution order

Match the exact line in the current revision.
Fall back to the diff hunk offset when lines shift.
Drop to file-level when the function is removed.
💡

Use fetch_anchor/2 for the result-tuple shape; reserve get_anchor/2 for the nil-on-miss shape.
