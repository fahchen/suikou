SReview: phone storyboard

The Suikou Review page as a phone companion to the desktop Review storyboard, in the same Suikou Light skin. The desktop three-pane workspace collapses to one column inside a phone device frame (~390px): a slim app bar on top, the editor filling the width, comments shown full and inline at their line, and the file navigator and Submit presented as bottom sheets instead of permanent panes. A cool off-white desk over a faint teal/blue wash, near-white glass slabs with thin hairline rings, the same cyan to teal to blue accent spent sparingly plus amber for numbers, the same green/red diff rows, monochrome file glyphs, and the agent reply idioms (>_ command pills, Applied notes). All states ride the one example file set: router.ex, schema.ex, store.ex, a markdown doc, a diff, and an html file.
