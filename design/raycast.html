Suikou, as a Raycast extension

Not a themed web page. Suikou modeled from Raycast's real primitives: one fixed 750px window and a navigation stack. Each action pushes a view; a back chevron pops it. List, List with Detail, ActionPanel, and Form, with a persistent bottom action bar.
