BDR-0017.mdspec/decisions

Anchor selectors

A line-scoped comment carries an anchor that locates it inside a snapshot. For text, markdown, and code the anchor is a line_range: a start line, an end line, and the captured quote of those lines.

Re-anchoring

On each new round we resolve the stored position by locating the captured quote. An unchanged line reports its present position; an edited or deleted line flags the comment outdated.

def reanchor(comment, snapshot) do
  case locate(snapshot, comment.quote) do
    {:ok, range} -> put_anchor(comment, range)
    :error     -> mark_outdated(comment)
  end
end
